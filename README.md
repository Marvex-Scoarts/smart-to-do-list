# Smart To-Do List Application

A clean, responsive To-Do List web app built with HTML, CSS, and JavaScript.

## Features
- **Add & Delete Tasks:** Quickly create new tasks and remove ones you no longer need.
- **Mark as Completed:** Check off tasks with an automatic strikethrough effect.
- **Smart Filters:** Switch between **All**, **Active**, and **Completed** tasks.
- **Local Storage:** Automatically saves your tasks in the browser so nothing disappears when you refresh the page.

## Built With
- HTML5
- CSS3 (Flexbox & Custom Styling)
- Vanilla JavaScript
